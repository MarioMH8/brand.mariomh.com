## Installation

```bash
npm install --save @mariomh/tailwind
```

**Using bun**

```bash
bun add @mariomh/tailwind
```

## How to use

Create a `index.css` file in your project and import the plugin.

```css
@import "tailwindcss";
@import "@mariomh/tailwind";
```
