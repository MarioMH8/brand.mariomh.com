## Instalación

```bash
npm install --save @mariomh/tailwind
```

**Usando bun**

```bash
bun add @mariomh/tailwind
```

## Como usarlo

Crear un archivo `index.css` en tu proyecto e importar el plugin.

```css
@import "tailwindcss";
@import "@mariomh/tailwind";
```
